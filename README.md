# 索图外勤（SuoTu Field）

在没有索图平台的环境里做日志取证排查的 agent skill。

核心思想一句话：**确定性的粗活全部交给命令行工具，LLM 只做判断**——
工具纵切，模型精读，人做裁决。

## 是什么

一份可被 dsh / Trae / Kimi Code 等 agent 环境加载的 SKILL.md（+ 参考卡）。
它把索图平台的排查方法论拆解成「公开工具 + 纪律 + 流程」：

- **拆解式工具箱**：ripgrep / duckdb / jq / evtx_dump / hayabusa 五个公开工具
  现场组装分析管线（GB 级日志不塞上下文，纵切后只让可疑子集进模型视野）；
- **纪律为纲**：先哈希再动手、原件只读、内容永不执行、强制落盘、
  产物透明、永不代删、命中≠结论（候选待人裁决）；
- **四段漏斗**：盘点 → 识别与纵切 → 狩猎 → 精读与候选；
- **降级阶梯**：缺工具直接降级浅层分析并如实标注边界，不纠缠用户。

## 目录

- `SKILL.md` —— skill 主体（铁律/开局协议/工作流程/场景应变）
- `references/tools.md` —— 五工具使用卡（Windows/Linux 双语境，命令全部实测）
- `references/patterns.md` —— 狩猎模式集（签名+六类统计异常+evtx/Java 应用日志组）
- `references/report-contract.md` —— 候选与报告输出契约
